Logic Tree Conditions

Used in Advanced Target Filtering. This script must return a boolean (`true` or `false`) to determine if the target is valid.

Signature:
function (target, source, state, eventPayload, engine) { ... }

Example:
return target.strength < source.strength;

Action Payloads

Used in Executed Actions. This script performs state manipulation. It does not need to return anything.

Signature:
function (state, target, params, engine, actionDepth) { ... }

Example:
target.health += 1;
state.history_log.push(`✨ ${target.name} gained 1 health.`);

Language Generation Placeholders

Special tokens you can use in the Script Language Description or Ability Description (Override) fields to let the engine dynamically format nouns and pronouns based on the target.

  • {TARGET} - The target's noun or pronoun (e.g., them, the chosen unit, all enemies).
  • {POSS} - The target's possessive form (e.g., their, its, the enemy's).
  • {SELF} - Always translates to this card.
  • {SELF_POSS} - Always translates to this card's.
  • {REFLEXIVE} - Translates to themselves or itself (based on target plurality).
  • {REFLEXIVE_POSS} - Translates to their own or its own.
  • {OMIT_TARGET} - Add this anywhere in the text to prevent the engine from automatically appending the target noun at the end of the sentence.
  • {PER_TARGET} - Appends "for each [target]" based on the group.
  • @[Ability Name] - Creates a linked, highlighted glossary tag for another ability.

Entity Object

Represents a Card, Unit, Avatar, Equipment, Artifact, Spell, or Boon.

  • instanceId (String): Unique runtime ID.
  • id (String): Catalog archetype ID.
  • name (String)
  • type (String): 'unit', 'avatar', 'spell', etc.
  • ownerId (String): 'player1' or 'player2'.
  • tribe, family, genus (String)
  • health, maxHealth, strength, power, armor, cost (Number)
  • readiness (Number): 1 (Ready), 0 (Unready), -1 (Exhausted).
  • line (String): 'front', 'mid', 'back', 'sheltered', 'sideline', 'taunt', 'bodyguard'.
  • abilities (Array): Array of Ability objects.
  • activeEffects (Array): Array of ongoing state modifiers.
  • attachments (Array): Array of Entity objects attached to this host.

GameState Object

The global state of the match.

  • activePlayerId (String): 'player1' or 'player2'.
  • turnPhase (String): e.g. 'ACTION_PHASE'.
  • players (Object): Contains player1 and player2.
  • players[pId].lines[lineName] (Array): Arrays of Entity objects on the board.
  • players[pId].hand, .deck, .discard, .banish (Array)
  • players[pId].resources (Object): Contains Carnie: { current, max } and others.
  • equator (Array): Array of Entity objects in the center zone.
  • history_log (Array): Used to log events. Use state.history_log.push(string) or push({text: string, depth: int}).

GameEngine Object

The rules orchestrator. Provides utility functions for triggering events.

  • engine.executeAbility(abilityObj, sourceEntity, eventPayload): Forces an ability to execute.
  • engine.utils.hasEngineFlag(state, entity, flagName): Checks if an entity has a flag (e.g., 'STRIKE_FAST').
  • engine.utils.randomInt(state, min, max): Seed-safe deterministic random number generation.
  • engine.utils.findEntityLocation(engine, target): Returns { playerId, zone, array, index, host }.
